# Neomarketing

Marketing agency site for **neomarketing.cloud** — services catalog with add-to-cart and checkout.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home
- `/services` — Full services catalog
- `/cart` — Cart
- `/checkout` — Project request checkout
- `/contact` — Contact
